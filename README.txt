REMEMBRANCE DAY PAGE
====================
Files
  index.html   The page. You normally never need to edit this.
  config.js    Track list, slideshow link and video link. Edit this.
  audio/       The mp3 files.
  video/       Optional: create this folder yourself if you want to use a video file.

Putting it on GitHub Pages
  1. Unzip this folder on your computer.
  2. In your GitHub repository choose Add file > Upload files and drag in
     index.html, config.js, and the audio folder (plus a video folder, if you use one).
     Commit the changes.
  3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
  4. Open https://YOUR-USERNAME.github.io/YOUR-REPO/ after a minute or two.

Changing things later
  - New slideshow or video link: edit config.js and commit.
  - New or replaced audio: upload the mp3 to the audio folder and make
    sure the name in config.js matches.

You can also open index.html straight from the unzipped folder, but the
YouTube video will show Error 153 that way. Use the website address instead.
