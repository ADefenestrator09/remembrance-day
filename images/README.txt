PUT YOUR PICTURES HERE
======================

1. Upload your pictures (JPG or PNG) into this folder.
   Tip: about 1920 pixels on the long side is plenty, and under 1 MB each
   keeps the page quick. Only add pictures you are allowed to share, because
   the repository is public.

2. Open config.js and list them under  gallery:  for example

     gallery: [
       { src: "images/photo1.jpg", caption: "Optional caption" },
       { src: "images/photo2.jpg" },
       { text: "Lest we forget" }
     ],

   File names must match exactly, including capital letters.

See README.txt (one folder up) for all the slideshow settings.
